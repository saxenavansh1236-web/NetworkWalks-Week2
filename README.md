# NetworkWalks – Week 2 Cybersecurity Project

## Overview
This project documents practical cybersecurity activities completed as part of NetworkWalks Week 2.

## Modules

### W2-PM1: Footprinting and Reconnaissance
- WHOIS lookup
- DNS enumeration
- Website technology identification using WhatWeb
- HTTP header inspection using cURL
- WAF detection using WAFW00F
- DNS reconnaissance using DNSRecon

### W2-PM5: Network Scanning
- Local network discovery using Nmap and Zenmap
- Host identification
- MAC address discovery
- Network topology documentation

## Tools Used
- Kali Linux
- Nmap / Zenmap
- WHOIS
- DIG
- DNSRecon
- WhatWeb
- WAFW00F
- cURL

## Report and Evidence
This repository contains the project report and supporting scan outputs, network inventory, and topology evidence.

## Disclaimer
All network scanning and reconnaissance activities were performed for educational purposes on the specified project target and local lab network, within the authorised scope.
